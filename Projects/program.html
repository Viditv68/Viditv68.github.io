Crowd Sort

C# · Unity · UniRx · DOTween

  • Built the project from scratch as the only developer, alongside one designer, one artist and one animator.
  • Took requirements from the designer and built an in-play level tool: tile count, blockers on tiles and per-level difficulty are all set during gameplay and saved automatically — designers never touch a JSON file or a scriptable object.
  • Integrated analytics and ads.
  • Worked with third-party plugins including analytics, UniRx and DOTween.
  • Shipped the whole project in 16 days.
