Lokko

A Unity title with Sony as publisher, in open beta on PS5, Steam and iOS, and showcased at BitSummit.

Trailer and thumbnail © Sony Interactive Entertainment. Opens on the official PlayStation channel.

What I built

  • Owned the full iOS architecture, including touch controls across every gameplay mechanic.
  • Engineered a reusable local PvP framework, so new levels need only level design, plus a wave-based enemy spawner with difficulty scaling.
  • Developed the two-player co-op robot level end to end: PS5 couch co-op on one console, with a pilot who drives and punches and a gunner whose blocks snap into platforms.
  • Optimised the in-game Level Editor and adapted it into a separate iOS project.
  • Set up platform-specific player and camera configs (speed, jump, roll) for iOS and console, using ScriptableObject-Architecture.
  • Created build tools that apply iOS or console animation sets automatically at build time, with a per-player animation report.
  • Delivered authentication on AWS Cognito (email OTP, account deletion via Amazon SES) and shipped the in-game wallet.
  • Mentored junior developers through code reviews and led knowledge-transfer sessions.

Crowd Sort

A mobile sorting game built from scratch in 16 days, with a level tool designers use during play.

The brief

A team of four: me as the only developer, plus one designer, one artist and one animator. The designer asked for a way to set up levels without hand-editing data files.

What I built

  • The full game, from scratch.
  • An in-play level tool: tile count, blockers and per-level difficulty are set during gameplay and saved automatically. Designers never touch a JSON file or a ScriptableObject.
  • Analytics and ads integration, plus third-party plugins including UniRx and DOTween.

The result

The whole project shipped in 16 days.
